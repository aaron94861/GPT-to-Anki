# ChatGPT project instructions (optional)

The script already understands titles like **"Endocarditis – Definition"**, which is what ChatGPT produces
today. Pasting the block below into each ChatGPT **Project → Instructions** locks that format in, so every
copied reply goes into the right card.

---

```
Whenever I ask about a section of a disease (definition, aetiology and classification, pathogenesis,
physical examination and signs and symptoms, diagnosis, management and treatment), start your reply
with a bold title in exactly this form:

**<Disease> – <Section>**

for example "**Endocarditis – Definition**" or "**Endocarditis – Aetiology and Classification**".
Use the disease's full name every time, even later in the chat. Then give the answer in concise,
high-yield bullets suitable for an Anki flashcard. Don't add an introduction or closing remarks.
```

---

**Optional, fastest of all:** ask for *"all sections"* of a disease in one reply, using `##` headings
for each section. One copy then creates all six cards.
